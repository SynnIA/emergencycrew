## 📖 L'histoire

**Emergency Crew** est né comme **projet scolaire d'équipe** — et a grandi, itération après itération, jusqu'à devenir un vrai jeu multijoueur jouable avec un lobby, un tutoriel et un ensemble complet de fonctionnalités en partie. Sur ce projet, j'ai principalement contribué au **développement** : fonctionnalités de jeu, logique client/serveur et déploiement.

## ✨ Fonctionnalités

- 🎮 Multijoueur temps réel (client + serveur de jeu)
- 🏠 Lobby & déroulement de partie
- ⚡ Power-ups
- 💀 Kill feed
- 😄 Emotes
- 📖 Tutoriel intégré

## 🧱 Tech & architecture

- **Frontend** — JavaScript · HTML · CSS (`client/`)
- **Backend** — serveur de jeu Node.js (`server/`)
- **Infra** — Docker · client sur Vercel, serveur de jeu sur VPS
